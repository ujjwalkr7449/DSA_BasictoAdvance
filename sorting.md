# 🔃 Sorting Algorithms in Python – DSA

A collection of important **Sorting Algorithms implemented in Python** for learning Data Structures and Algorithms (DSA), improving problem-solving skills, and preparing for coding interviews.

## 📌 About the Project

Sorting is the process of arranging data in a specific order, usually ascending or descending.

This project covers beginner to advanced sorting algorithms with Python implementations, time complexity, space complexity, and practical examples.

## 📚 Sorting Algorithms Covered

| No. | Algorithm | Best Time | Average Time | Worst Time |
|---|---|---|---|---|
| 1 | Bubble Sort | O(n) | O(n²) | O(n²) |
| 2 | Selection Sort | O(n²) | O(n²) | O(n²) |
| 3 | Insertion Sort | O(n) | O(n²) | O(n²) |
| 4 | Merge Sort | O(n log n) | O(n log n) | O(n log n) |
| 5 | Quick Sort | O(n log n) | O(n log n) | O(n²) |
| 6 | Heap Sort | O(n log n) | O(n log n) | O(n log n) |
| 7 | Counting Sort | O(n + k) | O(n + k) | O(n + k) |

## 🚀 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/your-username/sorting-algorithms-python.git
```

**2. Navigate to the project**

```bash
cd sorting-algorithms-python
```

**3. Run any sorting algorithm**

```bash
python bubble_sort.py
```

Replace `bubble_sort.py` with the algorithm file you want to execute.
